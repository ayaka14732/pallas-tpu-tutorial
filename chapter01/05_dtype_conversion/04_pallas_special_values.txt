## f32 → bf16（按位）
  0x3f808000 → 0x3f80（按 IEEE 就近舍入、保留非规格化数应为 0x3f80）  恰在中间，低位为偶
  0x3f818000 → 0x3f82（按 IEEE 就近舍入、保留非规格化数应为 0x3f82）  恰在中间，低位为奇
  0x3f808001 → 0x3f81（按 IEEE 就近舍入、保留非规格化数应为 0x3f81）  略大于中间
  0x3f817fff → 0x3f81（按 IEEE 就近舍入、保留非规格化数应为 0x3f81）  略小于中间
  0x7fc00001 → 0x7fc0（按 IEEE 就近舍入、保留非规格化数应为 0x7fc0）  静默 NaN，带载荷
  0x7f800001 → 0x7fc0（按 IEEE 就近舍入、保留非规格化数应为 0x7fc0）  发信号 NaN
  0xff800001 → 0x7fc0（按 IEEE 就近舍入、保留非规格化数应为 0xffc0）  负的发信号 NaN
  0x007fffff → 0x0000（按 IEEE 就近舍入、保留非规格化数应为 0x0080）  最大的非规格化数
  0x807fffff → 0x8000（按 IEEE 就近舍入、保留非规格化数应为 0x8080）  绝对值最大的负非规格化数
  0x80000001 → 0x8000（按 IEEE 就近舍入、保留非规格化数应为 0x8000）  绝对值最小的负非规格化数
  0x00800000 → 0x0080（按 IEEE 就近舍入、保留非规格化数应为 0x0080）  最小的规格化数
  0x7f7fffff → 0x7f80（按 IEEE 就近舍入、保留非规格化数应为 0x7f80）  最大的有限数
  0x7f7f7fff → 0x7f7f（按 IEEE 就近舍入、保留非规格化数应为 0x7f7f）  最大有限 bf16 加不到半个单位
